# 数据总览图初稿

- `data_pipeline_overview.svg`：可编辑矢量源图，展示六类数据、五步预处理与四问接口。
- `data_pipeline_overview.png`：便于快速预览的位图版本。
- `data_overview_table_preview.tex`：修正断行和列宽后的数据总览表独立预览源码。
- `data_overview_table_preview.pdf`：上述表格的编译预览。

当前版本用于讨论结构，尚未按论文栏宽、字号和黑白打印效果做最终优化。正式放入论文前建议：

1. 根据正文最终小节名称精简节点文字；
2. 决定保留彩色版还是改为灰度可辨的线型版；
3. 按论文实际版心导出 PDF 或高分辨率 PNG；
4. 图注建议使用“原始数据、统一预处理与各问题之间的关系”。
